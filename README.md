# ATX Regulated power supply
Turning almost any half-bridge ATX PSU into 1-30V and 0.1-10A regulated power supply

That was my second and successful try on turning standart PSU into regulated one. It's easier to repurpose the ones that have only 1 PWM and supervisor (2in1) IC. 
Among the pretty old ones that I had, I decided to pick the **FSP Group ATX300F** based on **FSP3528** PWM controller.
